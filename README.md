# 쓱싹의민족

한국어 홈케어 서비스 사이트입니다. HTML, CSS, JavaScript만 사용합니다.

## 실행

`index.html`을 브라우저에서 여세요. 별도 설치나 빌드가 필요하지 않습니다.
요청한 도현체(Do Hyeon)와 기랑해랑체(Kirang Haerang), 첨부 로고와 캐릭터 PNG가 모두 로컬에 포함되어 있습니다. 인터넷 연결 없이 표시됩니다. 글꼴 라이선스는 assets/fonts 안에 있습니다.

브랜드 색상은 블랙, 화이트, #6EEBD4입니다. 원본 캐릭터 이미지의 고유 색상은 보존했습니다.

로컬 서버 실행이 가능한 경우, 이 폴더에서 다음 명령을 사용해도 됩니다.

```
python3 -m http.server 8080 --bind 127.0.0.1
```

이후 http://127.0.0.1:8080 에서 확인하세요.

## 구현 기능

- 모바일·태블릿·데스크톱 반응형 화면
- 소개 장면 8개를 각각 화면 높이(100svh)로 표시
- 스크롤 스냅, 오른쪽 장면 탐색, 이전·다음 버튼
- 작은 화면에서 내용 자동 맞춤 및 FAQ 단일 펼침
- 주문 창과 주문 내역은 별도 대화상자로 유지
- 서비스 소개, 이용 방법, 펼침형 FAQ
- 3단계 주문: 주문 방식·항목 선택 → 날짜·시간·방문 정보 → 확인·저장
- 시간 쓱싹: 1~6시간 선택, 시간당 19,500원
- 마이크로 쓱싹: 화장실 19,000원/개, 주방 19,000원/개, 빨래 12,000원/회; 항목당 0~3 선택
- 추천 패키지: 기존 일상·정리·집중 패키지 및 공간 크기별 요금 유지
- 마이크로 주문은 작업 요금만 합산하고 공간 크기·추가 옵션 요금을 적용하지 않음
- 이전에 저장된 패키지 주문 내역과 호환
- 옵션별 예상 금액 계산, 필수 입력·휴대폰 번호·미래 날짜 검증
- 브라우저 localStorage 주문 저장 및 조회
- 주문 취소, UTF-8 텍스트 주문서 다운로드
- 키보드 조작, 대화상자, 모션 줄이기 설정 지원

## 실제 운영 전 연결할 항목

현재는 **주문 체험용**입니다. 주문은 해당 브라우저에만 저장되며 업체에 전송되지 않습니다. 방문 예약 확정, 결제, 실제 고객 정보의 운영용 처리는 구현되어 있지 않습니다. 체험에는 가상의 정보를 사용하세요.

실제 주문 서비스를 운영하려면 서버 API와 데이터베이스, 서버 측 가격·입력 검증, 방문 가능 일정·지역 확인, 관리자 주문 화면 및 알림, 결제대행사 연결, 실제 사업자·서비스 가격과 개인정보 처리 안내가 필요합니다. 가격은 모두 제작용 예시입니다.

## 수정

- `index.html`: 한국어 콘텐츠와 페이지 구성
- `style.css`: 기본 디자인과 주문 화면
- `screens.css`: 화면 한 장씩 표시하는 레이아웃과 반응형 스타일
- `script.js` 상단 `SERVICES`, `SIZES`, `EXTRAS`, `HOURLY_RATE`, `MICRO`: 서비스, 가격, 옵션
- `assets/logo.png`: 첨부 로고 원본
- `assets/character-*.png`: 첨부 캐릭터 6종 원본
- `assets/fonts/`: 도현체·기랑해랑체와 라이선스
